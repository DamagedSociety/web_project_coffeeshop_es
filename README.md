# Triple Espresso - Sitio Web de Reservas

Mi objetivo es dominar estas herramientas para convertirme en un desarrollador Full Stack aportando valor y soluciones en desarrollo de proyectos WEB.

## Descripción del Proyecto

En este proyecto se desarrolla una página WEB para una cafetería de especialidad llamada "Triple Espresso". El objetivo es proporcionar una plataforma amigable y funcional para que los clientes reserven una mesa, conozcan el horario de atención y la ubicación del establecimiento.

### Tecnologías Utilizadas

- HTML5 para la estructura del contenido.
- CSS3 para el diseño visual, la adaptabilidad y el estilo.

  (En desarrollo)

- _JavaScript_ para la interactividad y la validación del formulario de reserva.

## Instalación

Para ejecutar este proyecto de forma local, sigue estos sencillos pasos:

1. **Clona el repositorio:**
   Abre tu terminal y escribe el siguiente comando:

   ```bash
   git clone https://github.com/DamagedSociety/web_project_coffeeshop_es.git
   ```

2. **Abre el archivo en tu navegador:**
   Navega hasta la carpeta del proyecto y abre el archivo `index.html` en tu navegador web de preferencia, o utiliza una extensión como "Live Server" en tu editor de código para una experiencia automática.
