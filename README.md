# Triple Espresso

Proyecto de landing page para la cafetería Triple Espresso, desarrollado con un enfoque en diseño moderno y experiencia de usuario. El proyecto destaca por su interfaz limpia, una clara presentación de los horarios de atención, la ubicación y secciones dedicadas para reservas y contacto, todo estructurado para ofrecer una navegación intuitiva y atractiva.

Tecnologías usadas :
HTML
CSS
